# Praktika 2b — ideede hindamine

## Hindamise tabel

| Idee | Mõju 1–5 | Teostatavus 1–5 | Risk (madal / keskmine / kõrge) | ROI (umbes) | Kvadrant |
|---|---|---|---|---|---|
| | | | | | |

### Mõju (1–5)
1 = mugavus ühele inimesele · 3 = mõõdetav ajavõit tiimile · 5 = mõjutab kliendi kvaliteeti, kiirust või raha

### Teostatavus (1–5)
1 = vajab uut süsteemi, ligipääse ja kuid tööd · 3 = tööriistad olemas, vaja seadistada ja testida · 5 = saab homme olemasolevate tööriistadega proovida

### Risk
Kolm küsimust: **andmete tase** (avalik → saladus) × **agendi iseseisvus** (soovitab → teeb mustandi → tegutseb ise)
× **pöörduvus** (kas vea saab tagasi võtta?). Kui kaks kolmest on „kõrge“ → risk kõrge.

### ROI (umbes)
**(aeg korra kohta × korda kuus × tunnihind) − (ehitamine + hooldus + litsentsid)**
Ilma lähtetasemeta (praegune aeg) ROI-d ei ole — on ainult tunne.

## Mõju × teostatavuse maatriks

| | **Teostatavus kõrge (4–5)** | **Teostatavus madal (1–3)** |
|---|---|---|
| **Mõju kõrge (4–5)** | ✅ **Kiired võidud** — alustage siit | 🎯 **Strateegilised** — planeerige, jagage osadeks |
| **Mõju madal (1–3)** | 🔧 **Täiteülesanded** — tehke, kui aega jääb | ❌ **Ärge tehke** |
