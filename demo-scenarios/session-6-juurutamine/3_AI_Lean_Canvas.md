# Praktika 3 — AI Lean Canvas (meeskonniti)

**Põhimall on ideede tabelis (AI Lean Canvase leht).** See fail on sama sisuga varuvariant, kui tabel ei avane.

**Meeskond:** 2–4 inimest, kes teevad sarnast tööd (nt andmelao testijad koos, UI/API testijad koos).
Kes on projektis üksi või admin-töö peal, liitub meeskonnaga, kelle ülesanded on kõige sarnasemad.

**Idee:** üks konkreetne idee või kasutusjuht — eelistatult teie Praktika 2b top 3-st.

| # | Plokk | Küsimus | Teie vastus |
|---|---|---|---|
| 1 | **Probleem** | Mis täna võtab aega või läheb valesti? Kuni 3 punkti. | |
| 2 | **Kasutajad** | Kes seda probleemi tunneb ja kes lahendust kasutab? (rollid, mitu inimest) | |
| 3 | **Praegune lahendus ja lähtetase** | Kuidas seda täna tehakse — numbritega: kui kaua, kui tihti, kes. | |
| 4 | **AI-lahendus** | Mida teeb AI, mida inimene? Tööriist (Claude, ChatGPT, Copilot, agent, ajastatud ülesanne). | |
| 5 | **Andmed** | Milliseid andmeid on vaja, kust need tulevad ja mis tasemel (avalik / sisemine / klientide / saladus)? | |
| 6 | **Väärtus** | Miks see on parem kui praegu — ühe lausega. | |
| 7 | **Mõõdik ja „Valmis, kui“** | Mille järgi te teate, et töötas? Number enne → number pärast. | |
| 8 | **Kulud** | Aeg ehitamiseks ja hoolduseks, litsentsid, kelle aeg. | |
| 9 | **Riskid ja kontroll** | Mis võib valesti minna? Agendi iseseisvus (soovitab / teeb mustandi / tegutseb)? Kus on inimese kontroll? Peatamise kriteerium. | |

## Esitlus (Plokk E, ~4 min meeskonna kohta)

Probleem → AI-lahendus → mõõdik (enne → pärast) → suurim risk. Tagasiside: 1 tugevus · 1 küsimus · 1 risk.

## Edasi

- **Töötuba 1:** kaardistate protsessi, kuhu lahendus läheb (praegu → tulevikus).
- **Töötuba 2:** ehitate lahenduse ja esitlete tulemust — see on tunnistuse alus.
